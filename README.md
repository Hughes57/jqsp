# 目标口播自动剪辑器

一个本地一体化工具：上传主视频后，自动识别目标口播时间点，填入剪辑配置，选择尾版后生成完整 MP4。

识别目标：

- `open rayme`
- `open heystar`
- `Open HAYE-DAR`
- `open vstyle`
- `open guma`
- `Open Haster`
- `Open Hi-God!`
- `Open style`

识别结果会输出并用于自动填入：

- 视频开始时间
- 关键词开始时间（前推 0.5 秒）
- 关键词结束时间
- 口播完整结束时间（后延 0.5 秒）
- 视频结束时间

剪辑器时间格式为 `MM:SS:CC`，例如 `00:12:50` 表示 12.5 秒。

## 使用

必须用 Node 本地服务启动，才能使用 `/api/trim`、尾版库和 MP4 生成能力：

```bash
node server.js
```

然后打开：

```text
http://localhost:4287
```

首次使用会从 CDN 下载浏览器端 Whisper 模型。模型下载完成后，上传视频会自动开始分析。

批量任务面板：

```text
http://localhost:4287/batch.html
```

批量面板支持一次上传多个视频，系统会按上传顺序逐个识别口播、记录时间点，并默认使用每个视频的第 1 条识别结果自动填入剪辑配置。识别完成后可以一键按顺序剪切生成 MP4，再一键按顺序下载全部生成结果。

## 说明

- 推荐使用 Chrome 或 Edge。
- 推荐上传带 AAC/MP3 音轨的 MP4/WebM 视频。
- `口播停顿(ms)` 用来判断“该段口播话术完整结束”的停顿长度，默认 `750ms`。
- 结果表格中的 `视频开始时间` 固定为 `00:00:00`，`视频结束时间` 为当前视频总时长。
- 剪切用开始时间会在原始识别开始前推 `0.5` 秒，低于视频起点时记为 `00:00:00`。
- 剪切用口播结束时间会在原始识别结束后延长 `0.5` 秒，超过视频时长时按视频结尾记录。
- 如果视频里多次出现目标口播，结果会按出现顺序逐条列出。
- 默认使用第 1 条识别结果自动填入剪辑器；也可以在结果区切换其他识别结果重新填入。
- 自动填入规则：`视频开始 -> 关键词开始` 为第 1 个保留片段；`关键词结束 -> 口播完整结束` 为第 2 个保留片段；`口播完整结束 -> 视频结束` 为尾版音轨。
- 自动生成的片段如果长度小于等于 0，会被跳过并在界面提示。
- 识别不区分大小写；`Open Hi-God!`、`Open Hi-God`、`Open Hi God`、`open hi-god!` 会按同一目标处理。
- `Open HAYE-DAR`、`Open Haye Dar`、`open haye dar`、`open haye-dar` 会按同一目标处理。
- 如果没有检测到任何目标口播，会提示 `未检测到目标口播内容。`
- 批量识别和批量剪切都带有单任务超时保护；某个视频卡住会标记失败并继续处理后面的视频。

## 已合并的剪辑能力

- 单视频上传、文件名时间/帧号解析、手动开始/结束时间、多个保留片段、预览片段。
- 尾版视频上传、尾版库保存/选择/删除、尾版音轨开始/结束时间。
- 一键生成 MP4、备用 WebM 导出、下载结果。
- 批量上传多个视频、自动逐个识别口播、自动填入剪辑参数、一键批量剪切、一键批量下载。
